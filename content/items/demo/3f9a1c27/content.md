## DNA 是什么？

DNA（脱氧核糖核酸）是几乎所有生物的遗传物质。它像一本**生命的说明书**，记录着建造和维持一个生物体所需的全部信息——从眼睛的颜色，到细胞如何制造能量。

### 双螺旋结构

DNA 由两条长链相互缠绕，形成著名的**双螺旋**结构（1953 年由 Watson、Crick 基于 Franklin 的衍射数据共同揭示）。每条链由四种**碱基**串联而成：

| 碱基 | 名称 | 配对规则 |
| ---- | ---- | -------- |
| A | 腺嘌呤 | 与 T 配对 |
| T | 胸腺嘧啶 | 与 A 配对 |
| G | 鸟嘌呤 | 与 C 配对 |
| C | 胞嘧啶 | 与 G 配对 |

> **碱基互补配对原则**：A–T、G–C。这意味着只要知道一条链的序列，就能写出另一条链——这正是 DNA 能够精确复制的基础。

### DNA 如何指导生命活动？

基因——DNA 上有功能的片段——通过「**转录**」生成 RNA，再通过「**翻译**」合成蛋白质。蛋白质承担着催化化学反应、构成细胞结构、传递信号等几乎所有细胞工作。

这个「DNA → RNA → 蛋白质」的信息流动方向，被称为**分子生物学的中心法则**。

### 为什么它如此重要？

- **遗传**：DNA 复制把遗传信息从亲代传递给子代
- **变异与进化**：序列的偶然改变产生了多样性，是进化的原材料
- **生物技术**：PCR、DNA 测序、基因编辑（如 CRISPR）都建立在 DNA 结构与配对原则之上
